1. ASAL WAJA (Mobile Browser vs Native Android APK)
--------------------------------------------------------------------------------
Android OS ki security policy ke tehat, Chrome, Vivo Browser ya koi bhi web browser
ek "Sandbox" mein chalta hai. Android OS kisi bhi website ko yeh permission 
NAHI deta ke woh:
- Mobile ka Home button disable kar sake.
- Recent Apps (task switcher) button disable kar sake.
- Phone ki Status Bar / Notification shade ko pull-down hone se rokay.
- Phone ko Settings mein jakar app band karne se rokay.

Agar website ko yeh permissions mil jayen to internet par koi bhi malicious website
har bande ka phone permanently freeze kar sakti hai.

Yeh APK Android ke 4 power-level features use karti hai:
1) DeviceAdminReceiver: Phone ki Settings mein ja kar Uninstall ka button gayab kar deta hai.
2) startLockTask() (Kiosk Mode): Android ke Home aur Recent Apps buttons ko completely lock kar deta hai.
3) SYSTEM_ALERT_WINDOW (Draw Over Other Apps): Notification bar ko ooper se kheenchne nahi deta.
4) WebBridge Native Interface: Jab aap laptop se "LOCK" dabate hain, yeh web se direct Android OS ko signal bhejta hai ke phone freeze kar do.

3. VIVO / CUSTOMER PHONE PAR 1-TIME PERMISSION SETUP (ZAROORI)
--------------------------------------------------------------------------------
Jab pehli baar APK phone par open ho gi, yeh screen par 2 permissions mangegi:

1) "Display over other apps" (Draw over apps):
   Isko ALLOW karein taake lock screen ke ooper koi doosri app ya notification na aa sake.

2) "Device Administrator" (Device Admin):
   Screen par prompt aayega "Activate this device admin app".
   Isko "Activate" karein. Is se customer Settings -> Apps mein ja kar is app ko Uninstall nahi kar sakega.

3) Vivo Phone Special Setting:
   Vivo phones (Funtouch OS) mein:
   Settings -> Battery -> Background Power Consumption -> BashLock -> "High Background Power Usage" ALLOW karein.

4. PRO SHOPKEEPER ZERO-ESCAPE KIOSK MODE (DEVICE OWNER COMMAND)
--------------------------------------------------------------------------------
Agar aap chahte hain ke customer kisi bhi tarah Phone se nikal na sakay (jaise Samsung Knox ya commercial installment locking softwares karte hain):

1. Naye phone ko setup karte waqt (ya factory reset ke baad) phone mein USB Debugging on karein.
2. Laptop se USB cable lagayein.
3. Laptop terminal mein sirf yeh ek line command chalayein:

   adb shell dpm set-device-owner com.bashlock.apk/.BashLockDeviceAdminReceiver
